# Support

## Open-Source Projects

Use the issue tracker in the relevant repository for reproducible bugs and focused feature requests. Include the environment, steps, and expected result.

## JaydenART Services

GitHub issues are not a customer-support channel for hosting, domains, billing, account access, or other JaydenART services. Please use the official support route provided with your service or visit [JaydenART.com](https://www.JaydenART.com).

## Security

Report vulnerabilities privately using the instructions in [SECURITY.md](SECURITY.md).
