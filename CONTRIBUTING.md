# Contributing

Thank you for taking the time to improve a JaydenART open-source project.

## Before You Start

- Check the repository README and existing issues first.
- Use an issue for bugs, proposals, or questions that need discussion.
- Keep reports focused on one reproducible problem.
- Never include passwords, API keys, customer details, private URLs, or account data.

## Good Bug Reports

Please include:

- What you expected
- What happened instead
- The smallest steps that reproduce it
- Browser, operating system, runtime, or product version when relevant
- A reduced example or redacted screenshot when it helps

## Pull Requests

1. Fork the repository and create a focused branch.
2. Follow the repository's existing style and public writing rules.
3. Add or update tests when behavior changes.
4. Run the documented checks locally.
5. Explain the problem, the change, and how you verified it.

Small pull requests are easier to review and safer to ship. Please avoid unrelated cleanup in the same change.

By contributing, you agree that your work may be distributed under the repository's license.
