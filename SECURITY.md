# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability.

Use the repository's private security advisory form when it is available. Otherwise, email [GitHub@JaydenART.com](mailto:GitHub@JaydenART.com) with:

- The affected repository and version
- A clear description of the issue
- Reproduction steps or a minimal proof of concept
- The impact you believe is possible
- Any suggested mitigation

Do not send credentials, private customer data, or live production secrets. We will acknowledge a useful report and keep the discussion private while it is investigated.
